## 🌍 Overview

**Vidyut Sanchalak** is an AI-powered **Virtual Power Plant (VPP)** platform designed to intelligently monitor, forecast, and optimize renewable energy resources across campuses and institutions.

The platform integrates **solar panels**, **wind turbines**, **battery storage**, and the **power grid** into a unified system, enabling administrators to make data-driven decisions for maximizing renewable energy utilization while reducing operational costs and carbon emissions.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/banshikha/vidyut-sanchalak1.git
```

## Navigate

```bash
cd vidyut-sanchalak
```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

Application will start at

```text
http://localhost:5173
```
